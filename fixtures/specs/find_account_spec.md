# 화면기획서 — 비밀번호 찾기

문서번호: WITCHES-SCR-004
작성일: 2026-08-17
작성자: 기획팀

## 1. 화면 개요

| 항목 | 내용 |
|---|---|
| 화면 ID | find_account |
| 화면명 | 비밀번호 찾기 |
| 화면 경로 | /find-account |
| 설명 | 비밀번호를 잊은 회원이 이메일을 입력해 재설정 메일을 받는 화면 |

## 2. UI 요소 정의

| 요소 ID | 유형 | 라벨 | 필수 | 입력 검증 규칙 | 안내 문구 | 에러 메시지 |
|---|---|---|---|---|---|---|
| email | 입력 | 이메일 | 필수 | 이메일 형식(@ 포함) | 가입한 이메일을 입력하세요 | 올바른 이메일 형식을 입력하세요. |
| send_btn | 버튼 | 재설정 메일 받기 | - | - | - | - |

### 2-1. 입력 검증 규칙 상세

| 요소 ID | 규칙 | 값 |
|---|---|---|
| email | required | true |
| email | format | email |

## 3. 성공 조건

이메일이 형식 규칙을 만족하면, 같은 화면에 "재설정 메일을 보냈습니다." 문구를 노출한다.
화면 이동은 없다.

## 4. 실패 조건

| 상황 | 처리 |
|---|---|
| 필수 입력값이 비어 있음 | "필수 입력 항목입니다." 노출, 이동하지 않음 |
| 이메일 형식이 올바르지 않음 | "올바른 이메일 형식을 입력하세요." 노출, 이동하지 않음 |

## 5. 보안 요구사항

**계정 존재 여부를 알려주지 않는다.** 입력한 이메일이 등록되어 있든 없든 화면의 반응은
완전히 같아야 한다. 등록 여부에 따라 다른 문구를 노출하면, 공격자가 이 화면으로 어떤
이메일이 가입되어 있는지 확인할 수 있다.

## 6. 예시 동작

| 이메일 | 노출돼야 하는 문구 | 노출되면 안 되는 문구 |
|---|---|---|
| user@test.com | 재설정 메일을 보냈습니다. | 등록되지 않은 이메일입니다. |
| nobody@test.com | 재설정 메일을 보냈습니다. | 등록되지 않은 이메일입니다. |

두 번째 행이 §5 의 요구사항이다. `nobody@test.com` 은 등록되지 않은 이메일인데,
등록된 이메일과 **똑같은 문구**가 나와야 한다.
