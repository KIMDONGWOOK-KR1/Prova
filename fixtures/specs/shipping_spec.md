# 화면기획서 — 배송지 등록

문서번호: WITCHES-SCR-009
작성일: 2026-09-23
작성자: 기획팀

## 1. 화면 개요

| 항목 | 내용 |
|---|---|
| 화면 ID | shipping |
| 화면명 | 배송지 등록 |
| 화면 경로 | /shipping |
| 설명 | 주문자가 물건을 받을 주소와 받는 사람을 등록하는 화면 |

## 2. UI 요소 정의

| 요소 ID | 유형 | 라벨 | 필수 | 입력 검증 규칙 | 안내 문구 | 에러 메시지 |
|---|---|---|---|---|---|---|
| recipient | 입력 | 받는 사람 | 필수 | 2자 이상 20자 이하 | 받는 분 성함 | 받는 사람은 2자 이상 20자 이하로 입력하세요. |
| postcode | 입력 | 우편번호 | 필수 | 숫자만 입력, 5자 | 우편번호 5자리 | 우편번호는 숫자 5자리로 입력하세요. |
| address | 입력 | 주소 | 필수 | 5자 이상 | 도로명 주소를 입력하세요 | 주소는 5자 이상 입력하세요. |
| detail_address | 입력 | 상세 주소 | 선택 | - | 동·호수 (선택) | - |
| request_msg | 선택 | 배송 요청사항 | 선택 | 선택 목록: 문 앞에 두기, 경비실에 맡기기, 배송 전 연락 | - | - |
| save_btn | 버튼 | 배송지 저장 | - | - | - | - |

**상세 주소와 배송 요청사항은 선택 항목이다.** 비워 두고 저장해도 성공해야 한다 —
아파트가 아닌 주소에는 동·호수가 없고, 요청사항이 없는 주문이 더 많다.

### 2-1. 입력 검증 규칙 상세

| 요소 ID | 규칙 | 값 |
|---|---|---|
| recipient | required | true |
| recipient | min_length | 2 |
| recipient | max_length | 20 |
| postcode | required | true |
| postcode | numeric | true |
| postcode | min_length | 5 |
| postcode | max_length | 5 |
| address | required | true |
| address | min_length | 5 |

## 3. 성공 조건

필수 입력 검증을 통과하면, 같은 화면에 "배송지가 저장되었습니다." 문구를 노출한다.
화면 이동은 없다.

## 4. 실패 조건

| 상황 | 처리 |
|---|---|
| 필수 입력값이 비어 있음 | "필수 입력 항목입니다." 노출, 이동하지 않음 |
| 받는 사람이 2자 미만이거나 20자 초과 | "받는 사람은 2자 이상 20자 이하로 입력하세요." 노출, 이동하지 않음 |
| 우편번호가 숫자가 아니거나 5자리가 아님 | "우편번호는 숫자 5자리로 입력하세요." 노출, 이동하지 않음 |
| 주소가 5자 미만 | "주소는 5자 이상 입력하세요." 노출, 이동하지 않음 |

## 5. 테스트 입력값

|---|---|---|
