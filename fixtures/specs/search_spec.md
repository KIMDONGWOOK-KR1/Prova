## 1. 화면 개요

| 항목 | 내용 |
|---|---|
| 화면 ID | search |
| 화면명 | 상품 검색 |
| 화면 경로 | /search |
| 설명 | 사용자가 검색어를 입력해 상품 목록에서 일치하는 항목을 찾는 화면 |

## 2. UI 요소 정의

| 요소 ID | 유형 | 라벨 | 필수 | 입력 검증 규칙 | 에러 메시지 |
|---|---|---|---|---|---|
| query | 입력 | 검색어 | 필수 | 2자 이상 50자 이하 | 검색어는 2자 이상 50자 이하로 입력하세요. |
| search_btn | 버튼 | 검색 | - | - | - |
| result_list | 목록 | 검색 결과 목록 | - | - | - |

### 2-1. 입력 검증 규칙 상세

**검색어**
- 필수 입력이다. 비어 있으면 에러 메시지를 노출한다.
- 최소 길이는 2자, 최대 길이는 50자다.
- 길이 규칙을 위반하면 "검색어는 2자 이상 50자 이하로 입력하세요." 를 노출한다.

### 2-2. 검색 동작 규칙

- 상품명에 검색어가 포함된 항목을 모두 찾는다.
- **영문 대소문자를 구분하지 않는다.** `notebook` 과 `Notebook` 은 같은 결과를 낸다.
- 결과가 있으면 결과 개수를 "검색 결과 N건" 형식으로 노출한다.
- 찾은 항목을 검색 결과 목록에 한 항목씩 렌더한다. 목록의 항목 수는 결과 개수와 같다.
- 결과가 없으면 "검색 결과가 없습니다." 를 노출하고 목록은 렌더하지 않는다.

## 3. 성공 조건

검색어가 입력 검증을 통과하면 검색을 수행하고 결과 개수와 목록을 노출한다.

## 4. 실패 조건

| 상황 | 처리 |
|---|---|
| 검색어가 비어 있음 | "검색어를 입력하세요." 노출, 검색하지 않음 |
| 검색어 길이 규칙 위반 | "검색어는 2자 이상 50자 이하로 입력하세요." 노출, 검색하지 않음 |
| 일치하는 상품이 없음 | "검색 결과가 없습니다." 노출 |
