# 화면기획서 — 방문 예약

문서번호: WITCHES-SCR-010
작성일: 2026-09-23
작성자: 기획팀

## 1. 화면 개요

| 항목 | 내용 |
|---|---|
| 화면 ID | booking |
| 화면명 | 방문 예약 |
| 화면 경로 | /booking |
| 설명 | 고객이 방문할 날짜와 시간을 골라 예약하는 화면 |

## 2. UI 요소 정의

| 요소 ID | 유형 | 라벨 | 필수 | 입력 검증 규칙 | 안내 문구 | 에러 메시지 |
|---|---|---|---|---|---|---|
| visitor | 입력 | 예약자 | 필수 | 2자 이상 20자 이하 | 예약자 성함 | 예약자는 2자 이상 20자 이하로 입력하세요. |
| visit_date | 선택 | 방문 날짜 | 필수 | 선택 목록: 2026-10-15, 2026-10-16, 2026-10-17 | - | 방문 날짜를 선택하세요. |
| visit_time | 선택 | 방문 시간 | 필수 | 선택 목록: 10:00, 14:00, 18:00 | - | 방문 시간을 선택하세요. |
| people | 입력 | 인원수 | 필수 | 숫자만 입력, 1자 이상 2자 이하 | 1~20 | 인원수는 1~20 사이의 숫자로 입력하세요. |
| memo | 입력 | 요청사항 | 선택 | - | 남기실 말씀 (선택) | - |
| book_btn | 버튼 | 예약하기 | - | - | - | - |

**방문 날짜와 방문 시간을 모두 목록에서 고른다.** 예약 가능한 날짜와 시간이
정해져 있으므로 자유 입력을 받지 않는다 — 받으면 영업하지 않는 날짜가 들어온다.

### 2-1. 입력 검증 규칙 상세

| 요소 ID | 규칙 | 값 |
|---|---|---|
| visitor | required | true |
| visitor | min_length | 2 |
| visitor | max_length | 20 |
| visit_date | required | true |
| visit_time | required | true |
| people | required | true |
| people | numeric | true |
| people | min_length | 1 |
| people | max_length | 2 |

## 3. 성공 조건

모든 필수 입력 검증을 통과하면, 같은 화면에 "예약이 접수되었습니다." 문구를
노출한다. 화면 이동은 없다.

## 4. 실패 조건

| 상황 | 처리 |
|---|---|
| 필수 입력값이 비어 있음 | "필수 입력 항목입니다." 노출, 이동하지 않음 |
| 예약자가 2자 미만이거나 20자 초과 | "예약자는 2자 이상 20자 이하로 입력하세요." 노출, 이동하지 않음 |
| 방문 날짜를 고르지 않음 | "방문 날짜를 선택하세요." 노출, 이동하지 않음 |
| 방문 시간을 고르지 않음 | "방문 시간을 선택하세요." 노출, 이동하지 않음 |
| 인원수가 숫자가 아니거나 2자리를 넘음 | "인원수는 1~20 사이의 숫자로 입력하세요." 노출, 이동하지 않음 |

## 5. 테스트 입력값

| 예약자 | 방문 날짜 | 방문 시간 | 인원수 |
|---|---|---|---|
