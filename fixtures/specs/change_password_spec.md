# 화면기획서 — 비밀번호 변경

문서번호: WITCHES-SCR-008
작성일: 2026-09-23
작성자: 기획팀

## 1. 화면 개요

| 항목 | 내용 |
|---|---|
| 화면 ID | change_password |
| 화면명 | 비밀번호 변경 |
| 화면 경로 | /change-password |
| 설명 | 회원이 현재 비밀번호를 확인한 뒤 새 비밀번호로 바꾸는 화면 |

## 2. UI 요소 정의

| 요소 ID | 유형 | 라벨 | 필수 | 입력 검증 규칙 | 안내 문구 | 에러 메시지 |
|---|---|---|---|---|---|---|
| current_password | 입력 | 현재 비밀번호 | 필수 | - | 현재 비밀번호를 입력하세요 | - |
| new_password | 입력 | 새 비밀번호 | 필수 | 10자 이상, 대문자·소문자·숫자·특수문자 각 1자 이상 | 새 비밀번호를 입력하세요 | 새 비밀번호는 10자 이상이며 대문자·소문자·숫자·특수문자를 각 1자 이상 포함해야 합니다. |
| new_password_confirm | 입력 | 새 비밀번호 확인 | 필수 | 새 비밀번호와 동일한 값 | 새 비밀번호를 다시 입력하세요 | 새 비밀번호가 일치하지 않습니다. |
| save_btn | 버튼 | 변경하기 | - | - | - | - |

### 2-1. 입력 검증 규칙 상세

| 요소 ID | 규칙 | 값 |
|---|---|---|
| current_password | required | true |
| new_password | required | true |
| new_password | min_length | 10 |
| new_password | require_uppercase | 1 |
| new_password | require_lowercase | 1 |
| new_password | require_digit | 1 |
| new_password | require_special | 1 |
| new_password_confirm | required | true |
| new_password_confirm | same_as | new_password |

가입 화면(8자·대문자·특수문자)보다 규칙이 **네 종류로 늘었다.** 이미 쓰는 계정의
비밀번호를 바꾸는 자리이므로 더 엄격하게 본다.

## 3. 성공 조건

모든 입력 검증을 통과하고 현재 비밀번호가 맞으면, 같은 화면에 "비밀번호가
변경되었습니다." 문구를 노출한다. 화면 이동은 없다.

## 4. 실패 조건

| 상황 | 처리 |
|---|---|
| 필수 입력값이 비어 있음 | "필수 입력 항목입니다." 노출, 이동하지 않음 |
| 새 비밀번호가 규칙을 어김 | "새 비밀번호는 10자 이상이며 대문자·소문자·숫자·특수문자를 각 1자 이상 포함해야 합니다." 노출, 이동하지 않음 |
| 새 비밀번호 확인이 일치하지 않음 | "새 비밀번호가 일치하지 않습니다." 노출, 이동하지 않음 |
| 현재 비밀번호가 틀림 | "현재 비밀번호가 올바르지 않습니다." 노출, 이동하지 않음 |

## 5. 테스트 계정

| 현재 비밀번호 | 새 비밀번호 | 새 비밀번호 확인 |
|---|---|---|
| Abcd123! | NewPass12!x | NewPass12!x |

## 6. 예시 동작

입력 검증은 통과하지만 현재 비밀번호가 틀린 경우를 예시로 제시한다.
이 상황은 값의 규칙만으로는 만들 수 없다 — 규칙을 다 지킨 값이기 때문이다.

| 현재 비밀번호 | 새 비밀번호 | 새 비밀번호 확인 | 노출돼야 하는 문구 |
|---|---|---|---|
| Wrong99!x | NewPass12!x | NewPass12!x | 현재 비밀번호가 올바르지 않습니다. |
