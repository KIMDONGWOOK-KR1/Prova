## 1. 화면 개요

| 항목 | 내용 |
|---|---|
| 화면 ID | login |
| 화면명 | 로그인 |
| 화면 경로 | /login |
| 설명 | 기존 회원이 이메일과 비밀번호를 입력해 서비스에 로그인하는 화면 |

## 2. UI 요소 정의

| 요소 ID | 유형 | 라벨 | 필수 | 입력 검증 규칙 | 안내 문구 | 에러 메시지 |
|---|---|---|---|---|---|---|
| email | 입력 | 이메일 | 필수 | 이메일 형식(@ 포함) | 이메일을 입력하세요 | 올바른 이메일 형식을 입력하세요. |
| password | 입력 | 비밀번호 | 필수 | 8자 이상, 대문자 1자 이상, 특수문자 1자 이상 | 비밀번호를 입력하세요 | 비밀번호는 8자 이상이며 대문자·특수문자를 각 1자 이상 포함해야 합니다. |
| login_btn | 버튼 | 로그인 | - | - | - | - |

### 2-1. 입력 검증 규칙 상세

**이메일**
- 필수 입력이다. 비어 있으면 에러 메시지를 노출한다.
- `@` 를 포함한 이메일 형식이어야 한다. 형식이 맞지 않으면 "올바른 이메일 형식을 입력하세요." 를 노출한다.

**비밀번호**
- 필수 입력이다. 비어 있으면 에러 메시지를 노출한다.
- 최소 길이는 8자다.
- 영문 대문자를 1자 이상 포함해야 한다.
- 특수문자를 1자 이상 포함해야 한다.
- 위 규칙 중 하나라도 위반하면 "비밀번호는 8자 이상이며 대문자·특수문자를 각 1자 이상 포함해야 합니다." 를 노출한다.

## 3. 성공 조건

이메일과 비밀번호가 모든 입력 검증 규칙을 만족하고 등록된 계정 정보와 일치하면,
`/dashboard` 로 이동하고 "환영합니다" 문구를 노출한다.

## 4. 실패 조건

| 상황 | 처리 |
|---|---|
| 필수 입력값이 비어 있음 | "필수 입력 항목입니다." 노출, 이동하지 않음 |
| 이메일 형식이 올바르지 않음 | "올바른 이메일 형식을 입력하세요." 노출, 이동하지 않음 |
| 비밀번호 검증 규칙 위반 | "비밀번호는 8자 이상이며 대문자·특수문자를 각 1자 이상 포함해야 합니다." 노출, 이동하지 않음 |
| 등록되지 않은 계정 | "이메일 또는 비밀번호가 올바르지 않습니다." 노출, 이동하지 않음 |
| 같은 계정으로 5회 연속 실패 | "로그인 5회 실패로 계정이 잠겼습니다." 노출, 이동하지 않음 |

## 6. 예시 동작

같은 계정으로 틀린 비밀번호를 정해진 횟수만큼 제출했을 때의 안내를 예시로 제시한다.
이메일의 `{고유}` 는 실행마다 새 값으로 바뀌어, 다른 케이스의 계정을 잠그지 않는다.

| 이메일 | 비밀번호 | 시도 횟수 | 노출돼야 하는 문구 |
|---|---|---|---|
| nobody@test.com | Abcd123! | 1 | 이메일 또는 비밀번호가 올바르지 않습니다. |
| lock-{고유}@test.com | Abcd123! | 5 | 로그인 5회 실패로 계정이 잠겼습니다. |
