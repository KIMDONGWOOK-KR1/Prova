# 화면기획서 — 문의하기

문서번호: WITCHES-SCR-007
작성일: 2026-09-23
작성자: 기획팀

## 1. 화면 개요

| 항목 | 내용 |
|---|---|
| 화면 ID | contact |
| 화면명 | 문의하기 |
| 화면 경로 | /contact |
| 설명 | 회원·비회원이 문의 유형을 골라 내용을 남기고 답변받을 연락처를 남기는 화면 |

## 2. UI 요소 정의

| 요소 ID | 유형 | 라벨 | 필수 | 입력 검증 규칙 | 안내 문구 | 에러 메시지 |
|---|---|---|---|---|---|---|
| name | 입력 | 이름 | 필수 | 2자 이상 20자 이하 | 이름을 입력하세요 | 이름은 2자 이상 20자 이하로 입력하세요. |
| email | 입력 | 이메일 | 필수 | 이메일 형식(@ 포함) | 답변받을 이메일을 입력하세요 | 올바른 이메일 형식을 입력하세요. |
| phone | 입력 | 연락처 | 필수 | 010-0000-0000 형식 | 휴대폰 번호를 입력하세요 | 연락처는 010-0000-0000 형식으로 입력하세요. |
| category | 선택 | 문의 유형 | 필수 | 선택 목록: 결제, 배송, 환불, 기타 | - | 문의 유형을 선택하세요. |
| content | 입력 | 문의 내용 | 필수 | 10자 이상 500자 이하 | 문의 내용을 10자 이상 입력하세요 | 문의 내용은 10자 이상 500자 이하로 입력하세요. |
| agree_privacy | 체크박스 | 개인정보 수집 동의 | 필수 | - | - | 개인정보 수집에 동의해야 합니다. |
| submit_btn | 버튼 | 문의 접수 | - | - | - | - |

### 2-1. 입력 검증 규칙 상세

| 요소 ID | 규칙 | 값 |
|---|---|---|
| name | required | true |
| name | min_length | 2 |
| name | max_length | 20 |
| email | required | true |
| email | format | email |
| phone | required | true |
| phone | pattern | ^010-\d{4}-\d{4}$ |
| category | required | true |
| content | required | true |
| content | min_length | 10 |
| content | max_length | 500 |
| agree_privacy | required | true |

연락처는 **정규식으로 형식을 고정한다.** 이메일처럼 '@ 가 들어 있으면 통과' 가 아니라
자리수와 구분자까지 맞아야 한다 — 상담원이 그대로 전화를 걸 수 있어야 하기 때문이다.

## 3. 성공 조건

모든 입력 검증을 통과하면, 같은 화면에 "문의가 접수되었습니다. 답변은 입력하신 이메일로
보내 드립니다." 문구를 노출한다. 화면 이동은 없다.

## 4. 실패 조건

| 상황 | 처리 |
|---|---|
| 필수 입력값이 비어 있음 | "필수 입력 항목입니다." 노출, 이동하지 않음 |
| 이름이 2자 미만이거나 20자 초과 | "이름은 2자 이상 20자 이하로 입력하세요." 노출, 이동하지 않음 |
| 이메일 형식이 올바르지 않음 | "올바른 이메일 형식을 입력하세요." 노출, 이동하지 않음 |
| 연락처 형식이 올바르지 않음 | "연락처는 010-0000-0000 형식으로 입력하세요." 노출, 이동하지 않음 |
| 문의 내용이 10자 미만이거나 500자 초과 | "문의 내용은 10자 이상 500자 이하로 입력하세요." 노출, 이동하지 않음 |
| 개인정보 수집에 동의하지 않음 | "개인정보 수집에 동의해야 합니다." 노출, 이동하지 않음 |
