## 1. 화면 개요

| 항목 | 내용 |
|---|---|
| 화면 ID | signup |
| 화면명 | 회원가입 |
| 화면 경로 | /signup |
| 설명 | 신규 사용자가 계정 정보를 입력해 회원으로 등록하는 화면 |

## 2. UI 요소 정의

| 요소 ID | 유형 | 라벨 | 필수 | 입력 검증 규칙 | 에러 메시지 |

| email | 입력 | 이메일 | 필수 | 이메일 형식(@ 포함) | 올바른 이메일 형식을 입력하세요. |

### 2-1. 입력 검증 규칙 상세

**이메일**
- 필수 입력이다. 비어 있으면 에러 메시지를 노출한다.
- `@` 를 포함한 이메일 형식이어야 한다. 형식이 맞지 않으면 "올바른 이메일 형식을 입력하세요." 를 노출한다.

**비밀번호**
- 필수 입력이다. 비어 있으면 에러 메시지를 노출한다.
- 최소 길이는 8자다.
- 영문 대문자를 1자 이상 포함해야 한다.
- 특수문자를 1자 이상 포함해야 한다.
- 위 규칙 중 하나라도 위반하면 "비밀번호는 8자 이상이며 대문자·특수문자를 각 1자 이상 포함해야 합니다." 를 노출한다.

**비밀번호 확인**
- 필수 입력이다. 비어 있으면 에러 메시지를 노출한다.
- 비밀번호 항목에 입력한 값과 완전히 같아야 한다. 다르면 "비밀번호가 일치하지 않습니다." 를 노출한다.

**닉네임**
- 필수 입력이다. 비어 있으면 에러 메시지를 노출한다.
- 최소 길이는 2자, 최대 길이는 10자다.
- 길이 규칙을 위반하면 "닉네임은 2자 이상 10자 이하로 입력하세요." 를 노출한다.

**가입 경로**
- 필수 선택이다. 선택 목록은 검색, 지인 추천, 광고 세 가지다.
- 선택하지 않으면 "가입 경로를 선택하세요." 를 노출한다.

**약관 동의**
- 필수 항목이다. 체크하지 않으면 "약관에 동의해야 합니다." 를 노출한다.

## 3. 성공 조건

모든 입력 검증 규칙을 만족하면 `/welcome` 으로 이동하고
"가입이 완료되었습니다" 문구를 노출한다.
그 화면에 '로그인하러 가기' 링크를 두어 로그인 화면으로 이동할 수 있게 한다.

## 4. 실패 조건

| 상황 | 처리 |
|---|---|
| 필수 입력값이 비어 있음 | "필수 입력 항목입니다." 노출, 이동하지 않음 |
| 이메일 형식이 올바르지 않음 | "올바른 이메일 형식을 입력하세요." 노출, 이동하지 않음 |
| 비밀번호 검증 규칙 위반 | "비밀번호는 8자 이상이며 대문자·특수문자를 각 1자 이상 포함해야 합니다." 노출, 이동하지 않음 |
| 비밀번호 확인이 비밀번호와 다름 | "비밀번호가 일치하지 않습니다." 노출, 이동하지 않음 |
| 닉네임 길이 규칙 위반 | "닉네임은 2자 이상 10자 이하로 입력하세요." 노출, 이동하지 않음 |
| 가입 경로를 선택하지 않음 | "가입 경로를 선택하세요." 노출, 이동하지 않음 |
| 약관에 동의하지 않음 | "약관에 동의해야 합니다." 노출, 이동하지 않음 |
