# ARIA 격자(div role=grid) 탐지 — MUI Data Grid 공개 문서에서 (2026-09-30)

## 왜 쟀는가

React 데이터 그리드는 `<table>` 이 아니라 `div` 에 role 을 붙인다(grid > row > columnheader /
gridcell). 2026-09-30 까지 이 모양은 '찾을 수 없음' 으로 끝나, 목록 건수·정렬·날짜 필터 검증이
통째로 돌지 않았다. 격자 경로를 넣은 뒤(`dom_locator` `_locate_grid_by_name` ·
`_locate_grid_cells`), SUT 쌍둥이(`grid`/`badgrid`)만이 아니라 실물 데이터 그리드에서 어떻게
답하는지 봤다. 대상은 MUI X Data Grid 의 공개 문서 페이지 네 곳이다. 도구를 돌린 것이 아니라
탐지 함수(`count_items` · `collect_item_texts`)를 직접 불렀다.

## 결과

| 페이지 · 격자 | 물은 것 | 답 |
|---|---|---|
| column-definition · 이름 격자 (rowcount 6 · 그린 행 6) | First name / Last name 열 | **읽음** — Jon, Cersei, Jaime, Arya, … / Snow, Lannister, … (5개) |
| accessibility · 상품 격자 (rowcount 4 · 그린 행 4) | Product / Category 열 | **읽음** — Desk lamp, Office chair, Notebook / Lighting, Furniture, Stationery |
| accessibility · 거래 격자 (rowcount 5 · 그린 행 5) | Desk / Commodity 열 | **읽음** — D-3166, … / Sugar No.14, Oats, … (4개) |
| react-data-grid · 첫 격자 (rowcount 10 · 그린 행 6) | ID 열 | **멈춤** — 일부 행만 그려짐(한 페이지 5행 · 페이지 나눔) |
| react-data-grid · 둘째 격자 (스켈레톤 로딩) | Desk 열 | **멈춤** — 불러오는 중으로 보여 0건인지 알 수 없음 |
| react-data-grid · Commodity (격자 둘에 같은 머리글) | Commodity 열 | **멈춤** — 머리글 2개, 확정할 수 없음 |
| column-definition · age (격자 둘) | age 열 | **멈춤** — 머리글 2개 |

틀리게 읽은 것은 없었다. 못 읽은 것은 전부 이유를 말하며 멈췄다(시끄러운 실패).

## 측정 중에 막은 구멍 — 불러오는 중인 격자를 0건으로 읽었다

첫 확인에서 둘째 격자의 Desk 열이 **"0개 · 찾음"** 으로 나왔다. 스크린샷을 보니 격자는
스켈레톤 행을 그리며 데이터를 불러오는 중이었다. DOM 에는 `aria-rowcount=1`(머리글 행뿐)이고
데이터 행이 없었으며, **`aria-busy` 도 없었다** — 로딩을 알리는 표준 신호가 없다.

그대로 두면 '0건이어야 한다' 는 통과하고 'N건이어야 한다' 는 구현 결함으로 FAIL 한다(오탐).
그래서 데이터 행이 0개인데 **행 밖에 크기가 있고 글자가 없는 빈 요소가 셋 이상**이면 멈춘다.
'No rows' 같은 빈 격자 안내는 글자가 있어 걸리지 않고, 아무것도 그리지 않은 빈 격자(SUT 의
0건 화면)도 걸리지 않는다(`tests/test_grid_detection.py`).

이 규칙은 휴리스틱이다. 글자 없는 장식 요소를 셋 이상 그리는 빈 격자는 '불러오는 중' 으로
멈춘다 — 그때 결과는 0건 기대의 '확인 불가' 이지 오탐이 아니다.

## 점검에서 막은 구멍 — 한 열만 그린 격자의 행을 전부 안내 행으로 뺐다

안내 행('주문이 없습니다' 한 칸)을 가르는 격자 폭에 `aria-colcount` 를 넣었더니, 열 가상화로
한 열만 그린 격자(좁은 화면)에서 데이터 행이 모두 한 칸이라 전부 안내 행으로 빠졌다. 3건을
**ok · 0건** 으로 읽었다 — 'N건이어야 한다' 가 오탐 FAIL 한다. 폭은 그려진 행에서만 잰다
(`tests/test_grid_detection.py` `test_열_가상화로_한_열만_그렸어도_행은_행이다`).

## 한계

- 페이지를 나눈 격자는 aria-rowcount 가 전체 행 수라 늘 '일부 행만 그려짐' 으로 멈춘다.
  '이 페이지에 5건' 을 검증하려면 기획서가 그 말을 해야 하고, 지금은 만들지 않는다.
- AG Grid 공개 예제(`ag-grid.com/example`)는 이날 role=grid 요소를 찾지 못했다(0개) — 무엇을
  그렸는지는 보지 않았다.
- 격자 이름(aria-label)이 있는 실물은 이날 보지 못했다 — MUI 문서의 격자는 전부 이름이 없어
  건수 세기(`count_items` 목록 경로)는 SUT 쌍둥이로만 확인했다.
