# 화면기획서 — 상품 검색 (Automation Exercise)

문서번호: EXT-AE-001
작성일: 2026-09-23
작성자: 소인배 (사이트가 실제로 보이는 결과를 옮겨 적음 — 공개 문서 없음)

## 1. 화면 개요

| 항목 | 내용 |
|---|---|
| 화면 ID | ae_search |
| 화면명 | 상품 검색 |
| 화면 경로 | /products |
| 설명 | 상품명으로 상품을 찾는 화면 |

## 2. UI 요소 정의

| 요소 ID | 유형 | 라벨 | 필수 | 입력 검증 규칙 | 안내 문구 | 에러 메시지 |
|---|---|---|---|---|---|---|
| query | 입력 | 검색어 | - | - | Search Product | - |
| search_btn | 버튼 | 검색 | - | - | - | - |
| result_list | 목록 | 검색 결과 목록 | - | - | - | - |

### 2-1. 검색 동작 규칙

- 상품명에 검색어가 포함된 항목을 모두 찾는다.
- 검색하면 "Searched Products" 제목 아래에 찾은 상품을 한 항목씩 렌더한다.

## 3. 성공 조건

검색하면 "Searched Products" 문구를 노출한다.

## 6. 예시 검색

| 검색어 | 결과 건수 | 노출돼야 하는 문구 |
|---|---|---|
| jeans | 3 | Searched Products |
| dress | 9 | Searched Products |
