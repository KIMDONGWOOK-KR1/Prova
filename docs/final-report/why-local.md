# 왜 로컬 모델인가 — 외부 생성형 AI 에 자료를 올리지 못하는 근거 (2026-11-11 조사)

> 10-16 멘토링 과제("개인정보 유출 관련 뉴스를 근거 자료로 찾아 둘 것")의 답이다.
> 최종 보고서 1-2 절에 쓴다.
>
> **쓰기 전에 원문을 확인할 것.** 아래 내용은 검색 결과의 요약으로 모은 것이고, 기사 원문을
> 하나씩 열어 대조하지는 않았다. 날짜·숫자를 보고서에 옮길 때는 옆의 링크를 열어 확인한다.

## 한 줄 요약

화면기획서에는 출시 전 화면, 계정, 업무 규칙이 들어 있다. 외부 생성형 AI 에 올린 자료가
밖으로 나간 사고는 **직원이 올려서**, **서비스 쪽 결함으로**, **서비스가 제3자에게 넘겨서**
세 갈래로 모두 실제로 일어났다. Prova 는 기획서를 사내 GPU 의 모델로만 읽고, 그 모델은
우리 측정에서 외부 API 와 같은 결과를 냈다([4-6](outline.md), 105/105).

## 5. 반대쪽 사실 — 함께 적어야 하는 것

근거를 한쪽만 모으면 발표에서 바로 반박당한다. 아래는 '그래도 외부 AI 를 쓰면 된다' 쪽이다.

- **규제는 풀리는 중이다.** 금융위는 2026년에 망분리 전면 해제를 추진하고 있고
  ([디지털데일리](https://www.ddaily.co.kr/page/view/2026071517443276094)), 공공기관 업무 PC
  에서도 챗GPT 를 쓰게 하는 국가 망 보안체계(N2SF) 사업이 시작됐다
  ([뉴시스](https://mobile.newsis.com/view/NISX20260313_0003547805)). '법으로 못 쓴다' 는
  주장은 곧 틀린 말이 된다. 대신 풀어 주는 조건이 **민감 자료 입력 금지와 사고 책임 강화**
  라는 점이 우리 쪽 근거다.
- **기업용 요금제는 입력을 학습에 쓰지 않는다고 약속한다.** 그러면 1절(직원이 올린 자료가
  학습에 쓰일 위험)은 줄어든다. 2절(서비스 결함)과 3절(제3자 전송)은 요금제로 막는 문제가
  아니다. 요금제별 약관은 이번에 확인하지 않았다.
- **멘토가 말한 '기업용 계정은 비싸고 대부분 안 쓴다' 는 조사하지 않았다.** 근거 없이 쓰지
  않는다.
- **우리 비교는 한계가 있다.** 로컬 모델이 외부 API 와 같았다는 것은 공개 예시 기획서
  105항목에서이고(셋 다 만점), 실물 기획서로는 비교하지 못했다.

## 6. 보고서에 쓸 문장 (초안)

> 화면기획서는 출시 전 화면과 업무 규칙이 담긴 사내 자료다. 외부 생성형 AI 서비스에서는
> 직원이 올린 소스 코드가 밖으로 나간 사례(2023, 삼성전자), 서비스 결함으로 다른 이용자의
> 정보가 보인 사례(2023, 국내 687명·과태료 처분), 입력한 내용이 고지 없이 제3자에게 전송된
> 사례(2025, 개인정보보호위원회 실태점검)가 모두 있었다. 규제가 완화되는 지금도 조건은
> '민감 자료를 넣지 않는 것' 이다. Prova 는 기획서를 사내 GPU 의 4B 모델로만 읽으며, 같은
> 추출 과제에서 외부 API 모델과 결과가 같았다.
