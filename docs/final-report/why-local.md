# 왜 로컬 모델인가 — 외부 생성형 AI 에 자료를 올리지 못하는 근거

> 10-16 멘토링 과제("개인정보 유출 관련 뉴스를 근거 자료로 찾아 둘 것")의 답이다.
> 최종 보고서 1-2 절에 쓴다.
>
> **원문 대조 (2026-11-12).** 11-11 에 검색 요약으로 모은 초안을 기사 원문과 하나씩 대조해
> 고쳤다. 아래 표의 내용은 옆에 적힌 기사에 실제로 적혀 있는 것이다. 원문을 열지 못한 것은
> 맨 아래 '확인하지 못한 것' 에 따로 두었고 본문 근거로 쓰지 않는다.

## 한 줄 요약

화면기획서에는 출시 전 화면, 계정, 업무 규칙이 들어 있다. 외부 생성형 AI 에 올린 자료가
밖으로 나간 사고는 **직원이 올려서**, **서비스 쪽 결함으로**, **서비스가 제3자에게 넘겨서**
세 갈래로 모두 실제로 일어났다. Prova 는 기획서를 사내 GPU 의 모델로만 읽고, 그 모델은
우리 측정에서 외부 API 와 같은 결과를 냈다([4-6](outline.md), 105/105).

- **공공.** 행정안전부의 챗GPT 활용 안내서는 질문에 비공개 정보나 개인정보를 입력하지 않도록
  했고, 국가정보원은 국가기관이 AI 를 쓸 때 정부 차원 모델을 행정업무망 내부에 자체 구축하는
  형태가 돼야 한다고 말했다. 국정원은 보안 가이드라인을 그달 중 배포할 예정이라고 했다.
  ([뉴시스 2023-06-12](https://v.daum.net/v/20230612060221130)) 국정원은 2025년 12월 10일
  그 2023년 6월 가이드라인을 개정한 'AI 보안 가이드북'(보안 위협 15개, 보안 대책 30개)을
  중앙행정기관·지자체·공공기관에 배포했다.
  ([CIO Korea 2025-12-10](https://www.cio.com/article/4103809/%EA%B5%AD%EC%A0%95%EC%9B%90-ai-%EB%B3%B4%EC%95%88-%EA%B0%80%EC%9D%B4%EB%93%9C%EB%B6%81-%EB%B0%B0%ED%8F%AC%C2%B7%C2%B7%C2%B715%EA%B0%9C-%EC%9C%84%ED%98%91-%EB%B0%8F-30%EA%B0%9C.html))
- **금융.** 금융권은 망분리 도입 뒤 약 10년 동안 외부 통신 제한 때문에 생성형 AI 도입에

인용하지 않는다(가이드라인 원문은 확인하지 못했다).

## 5. 반대쪽 사실 — 함께 적어야 하는 것

근거를 한쪽만 모으면 발표에서 바로 반박당한다. 아래는 '그래도 외부 AI 를 쓰면 된다' 쪽이다.

- **규제는 풀리는 중이다.** 금융위원회는 2026년 7월 15일 업무보고에서 망분리 규제를 전면
  해제하겠다고 밝혔다. 생성형 AI·클라우드 활용 범위를 넓히는 대신 해킹·정보 유출 사고에 대한
  책임을 강화한다는 방침이고, 고객 정보를 외부 사업자에게 어디까지 넘길 수 있는지는 세부
  기준에서 정해야 하는 상태다.
  ([디지털데일리 2026-07-15](https://www.ddaily.co.kr/page/view/2026071517443276094))
  '법으로 못 쓴다' 는 주장은 곧 틀린 말이 된다.
- **공공기관도 생성형 AI 를 쓰게 된다 — 다만 등급에 따라.** 국가 망 보안체계(N2SF)는 정보를
  세 등급으로 나눈다. 대외 공개가 가능한 정보(O)는 생성형 AI·클라우드로 처리할 수 있고,
  유출되면 피해가 갈 수 있는 내부 비공개 정보(S)는 보안 통제 속에서 다루며, 안보·수사 등의
  정보(C)는 지금처럼 격리한다. 2025년 6개 기관 실증에 이어 2026년 45억 원 공모 사업으로
  도입을 지원한다. ([뉴시스 2026-03-15](https://mobile.newsis.com/view/NISX20260313_0003547805))
  **출시 전 화면기획서는 '내부 비공개 정보' 쪽이다** — 풀리는 규제도 그런 자료를 외부 AI 에
  자유롭게 넣으라는 것이 아니라는 점이 우리 근거다.
- **기업용 요금제는 입력을 학습에 쓰지 않는다고 약속한다.** 그러면 1절(직원이 올린 자료가
  학습에 쓰일 위험)은 줄어든다. 2절(서비스 결함)과 3절(제3자 전송)은 요금제로 막는 문제가
  아니다. 요금제별 약관은 확인하지 않았다.
- **멘토가 말한 '기업용 계정은 비싸고 대부분 안 쓴다' 는 조사하지 않았다.** 근거 없이 쓰지 않는다.
- **우리 비교는 한계가 있다.** 로컬 모델이 외부 API 와 같았다는 것은 공개 예시 기획서
  105항목에서이고(셋 다 만점), 실물 기획서로는 비교하지 못했다.

## 6. 보고서에 쓸 문장 (초안)

> 화면기획서는 출시 전 화면과 업무 규칙이 담긴 사내 자료다. 외부 생성형 AI 서비스에서는
> 직원이 입력한 소스 코드가 문제가 된 사례(2023, 삼성전자 보도), 서비스 결함으로 다른 이용자의
> 정보가 노출된 사례(2023, 국내 이용자 687명 포함·신고 지연으로 과태료), 입력한 내용이 고지나
> 동의 없이 해외 업체로 전송된 사례(2025, 개인정보보호위원회 실태점검)가 모두 있었다. 규제는
