## 4. 성과 지표 (계획서 4-6)

목표선은 계획서 5 마일스톤과 서비스명세서 §9 를 따른다.

### 4-1. GUI 요소 탐지 성공률 — 목표 90% 이상 (IoU 기준)

| 경로 · 시험지 | 탐지 성공(IoU≥0.5) | 적중(중심이 요소 안) | 없는 것을 있다고 함 |
|---|---|---|---|
| 1차 selector, SUT 63항목 | **61/63 = 96.8%** (selector 는 IoU 개념 없음 — 적중+관문 통과) | — | 0/14 |
| 2차 Qwen2.5-VL-3B, SUT 63항목 (08-31) | 36/63 = 57.1% | 57/63 = 90.5% | 10/14 = 71.4% |
| 2차 Qwen3.5-4B, SUT 63항목 (09-28) | 51/63 = 81.0% | 52/63 = 82.5% | 1/14 = 7.1% |
| 2차 Qwen3.5-4B, 외부 화면 40항목 (09-29) | **34/40 = 85.0%** | **36/40 = 90.0%** | 0/20 |

- 판정: 실제로 쓰는 1차 경로는 목표 넘음. 2차 경로는 IoU 기준 미달(85.0%), 클릭에 필요한 적중은 90.0%.
  IoU 미달의 원인은 상자 크기(입력란을 라벨까지 잡음)라는 해석 — 노트 13
- 근거: `grounding-selector-vs-vlm-2026-08-27.md`, `vlm-iou-qwen-vl-2026-08-31.md`,
  `model-compare-qwen35-4b-2026-09-28.md`, `vlm-iou-external-2026-09-29.md`

### 4-2. PASS/FAIL 판단 정확도 — 목표 90% 이상

**빈 곳.** '정답 라벨 대비 판정 일치율' 하나로 모은 측정이 아직 없다. 있는 것:
- SUT `good`/`bad`: 심은 결함을 전부 지목·오탐 0 (README 결과 표, 화면별)
- 외부 사이트 7곳: 첫 실패의 오탐을 고친 뒤 '기획서와 다름' 0 (`external-sites-*.md`)
- 실물 사이트: 실제 차이 11건 중 8건 탐지·오탐 0
- 변이 시험: 잴 수 있는 26 중 24 잡음 (`mutation-2026-11-07.md`)

**제안:** SUT 판정 덤프(`scripts/dump_verdicts.py`, 기획서 9 × 변형 12, mock, GPU 불필요)에
변형별 정답 라벨(good=전부 PASS, bad=심은 결함 목록)을 붙여 케이스 단위 일치율·혼동행렬을 낸다.
실물(8/11)과 변이(24/26)를 같은 표에 '다른 표본' 으로 나란히 둔다.

### 4-3. 테스트 케이스 생성 품질

- S1 골든 대조 105항목, 실물 기획서 엄격 82.2%(37/45)·처음 0%
- 커버리지 공백 보고(`s2_case_generator/coverage.py`) — 기획서에 있는데 확인하지 않는 것
- 사람이 고치는 단계(판단 30)
- 근거: `tests/test_s1_golden.py`, 노트 12·14

### 4-4. Self-Healing 복구율

- `nolabel`: 2차 경로 끔 1 PASS / 9 FAIL → 켬 9 PASS / 1 FAIL (실물 VL-3B, 4B 웹 UI 동일). 남은 1은 의도한 라벨 결함
- 보정 8건. 정체 대조 관문: 저장 답안 재생에서 오탐 6/6 차단·정상 보정 32건 오차단 0
- 한계: 같은 이름의 요소가 한 화면에 둘이면 정체 대조가 못 막음(`vlm-iou-external-2026-09-29.md`)

### 4-5. 리포트 완결성 — 목표 100%

- **채울 것:** 계획서의 다섯 칸(실행 로그·입력 데이터·기대 결과·실제 결과·실패 원인)이 리포트·엑셀
  어디에 있는지 칸별 체크표. `run.log`, 케이스 스텝, evidence 의 expected/actual, failure_category

### 4-6. 로컬 모델 vs 외부 API

**빈 곳.** 비교 측정을 하지 않았다. 로컬(7B → 4B)로 S1 골든 105/105 를 넘겨 API fallback 이
필요 없었다(노트 02). GPU 반납(11-13) 뒤라 로컬 쪽은 replay 응답으로만 비교할 수 있다.
**정할 것:** 공개 픽스처로 API 를 한 번 재서 표를 채울지, '필요가 없어 하지 않았다' 를 한계로 쓸지.
